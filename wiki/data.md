# Data access

## Where the data is

The full raw evidence cache is in the GitHub repository, not all as rendered HTML pages.

This project currently separates:
1. **Raw data** in the repo
2. **Registries / inventories** as navigable pages
3. **Derived wiki pages** as navigable pages

## Best entry points

### Hosted pages
- [Source registry](../inventories/source_registry.md)
- [Dispute index](../inventories/dispute_index.md)
- [Remibrutinib program](programs/remibrutinib.md)
- [Remibrutinib Phase 2b study](trials/remibrutinib-nct03926611-phase-2b.md)

### Raw data in the GitHub repo
- [ClinicalTrials.gov raw caches](https://github.com/zosyn-j/clinpharm-vault/tree/main/raw/clinicaltrials)
- [Sponsor raw caches](https://github.com/zosyn-j/clinpharm-vault/tree/main/raw/sponsors)
- [Publication raw caches](https://github.com/zosyn-j/clinpharm-vault/tree/main/raw/publications)
- [Inventories directory](https://github.com/zosyn-j/clinpharm-vault/tree/main/inventories)

## Current behavior

- The website is for browsing the synthesized layer and key inventories.
- The repository is where the full raw source cache currently lives.

## Next improvement

If needed, the site can later get richer data-browse pages for raw assets, but for now the authoritative full dataset is in the repo tree.
